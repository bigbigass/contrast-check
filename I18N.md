# I18N.md — add 7-language i18n to ContrastCheck

Goal: serve ContrastCheck in en (default at `/`), zh, es, de, fr, ja, pt (`/zh/`, `/es/`, `/de/`, `/fr/`, `/ja/`, `/pt/`) without breaking any existing English URL.

## Requirements
- Move pages under `app/[locale]/` with `generateStaticParams` for all 7 locales; English keeps current root URLs (rewrite, no redirect). All routes remain static.
- Existing English URLs must stay identical (no 404s, no redirects) — add a test listing the current routes.
- Dictionaries `lib/i18n/dictionaries/{locale}.json` typed from `en.json`; translate ALL copy: UI labels, WCAG result texts (AA/AAA, normal/large text), H1, meta title/description, explanatory content, FAQ, any landing pages. Native-quality, not literal.
- `<html lang>` per locale; header language switcher preserving current path (fire Vercel Analytics `track('locale_switch')`).
- `generateMetadata` on every page: self canonical + `alternates.languages` for 7 locales + `x-default` → English.
- `app/sitemap.ts`: every page × 7 locales with `alternates.languages`; robots unchanged except sitemap URL.
- JSON-LD (WebApplication/FAQPage) localized (`inLanguage`).
- Number/format strings via `Intl` where shown.

## Tests (Vitest)
- All dictionaries have identical key sets, no empty values.
- Sitemap contains every page × 7 locales, absolute URLs on https://contrastcheck.top (or `NEXT_PUBLIC_SITE_URL`).
- hreflang map for a sample page = 7 locales + x-default.
- Existing contrast logic tests still pass unchanged.

## Acceptance
`npm test` and `npm run build` pass; build shows all routes static; commit and push to main. Do not deploy.
